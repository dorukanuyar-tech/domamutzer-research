# Frozen public proxy evidence

These experiments are retained because they shaped the current architecture. They are **historical social-link proxies**, not production people-discovery experiments.

| Experiment | Gate | Main takeaway |
|---|---|---|
| GEMSEC Deezer | AMBER | Small positive top-K signal; uncertainty remained in Romania/Croatia. |
| GitHub social holdout | RED | The fixed symmetric feature family did not generalize. |
| Twitch 6-network holdout | RED | Macro NDCG@10 delta was negative; 2/6 networks were positive. |

The current public policy was designed *after* these experiments. We do not reopen these holdouts to tune v4. The decision-grade next test is a buyer-controlled replay with directional exposure/outcome labels.
